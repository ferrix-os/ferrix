# Notes for the authors (not part of the paper)

**PRIVATE.** This folder lives on the local branch `po7/paper` only. It is
never landed on `main` and never pushed: `main` is public and the review is
double-blind (customer, 2026-10-06).

**Who writes the text.** OSDI '27's call for papers treats "submission of
work wholly or largely generated by AI" as fraud, while allowing AI editing
tools; ACM venues require generative-AI use to be disclosed in the
acknowledgments. Everything in `paper.md` below the metadata is scaffolding
written by an agent session (po7-paper): the structure, the claims, the
evidence pointers and the owed markers. The prose of the submitted paper is
to be written by its human authors. The agents and their process are the
system under study, and are described as such.

**Building.** `./build.sh` writes `build/paper.pdf` with pandoc 3.12 and
tectonic 0.17.0 from `~/.local/share/ferrix/paper-tools/` (static release
binaries, sha256-checked against the GitHub release digests; not on PATH).
Override the directory with `PAPER_TOOLS=...`. `build/` is not committed.
The citation style is `csl/ieee.csl` (CSL project, CC BY-SA 3.0, commit
1ccf4696 of citation-style-language/styles). The layout approximates the
USENIX format (letter, 10 pt, two columns, 7 × 9 in text block, Times-like
font). A venue's own class or style file (e.g. `usenix-2020-09.sty`, or
`acmart.cls` for ACM venues) is not committed; drop it into `template/` and
set `documentclass` or `header-includes` in `paper.md`'s metadata.

## Title options

1. *Fast Paths for Every Machine: Agent-Driven Specialization Makes
   Microkernel IPC Competitive Again*
2. *Liedtke's Labour, Automated: Per-Hardware IPC Fast Paths Written by
   Coding Agents*
3. *Hot-Path Instructions: Letting AI Agents Specialize a Certifiable
   Microkernel to Its Hardware*
4. *From 37 µs to seL4: An Agent-Built IPC Path for a Rust Microkernel*
   (only if the final figure reaches seL4's)

Option 1 states the thesis; option 2 places it in the literature; option 4 is
the honest title for an experience paper if the cross-hardware results are
not in.
